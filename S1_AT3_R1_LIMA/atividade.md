# Projeto HTML - Apresentação Pessoal

## Descrição

Este projeto consiste em uma página desenvolvida utilizando apenas HTML5. O objetivo é apresentar informações pessoais, interesses, hobbies e metas profissionais por meio da estrutura básica de uma página web.

O projeto foi desenvolvido como atividade prática para reforçar os conceitos fundamentais da linguagem HTML, como organização do conteúdo, utilização de títulos, parágrafos, listas e seções.

## Tecnologias Utilizadas

* HTML5

## Estrutura da Página

A página é composta pelos seguintes elementos:

* Apresentação pessoal
* Breve descrição sobre formação e interesses
* Plano profissional
* Lista de hobbies
* Rodapé com uma reflexão sobre aprendizado e desenvolvimento

## Objetivos de Aprendizagem

Durante o desenvolvimento deste projeto foram praticados os seguintes conceitos:

* Estrutura básica de um documento HTML
* Utilização das tags `<html>`, `<head>` e `<body>`
* Criação de títulos utilizando `<h1>` e `<h2>`
* Organização de conteúdo com `<section>`
* Inserção de parágrafos com `<p>`
* Criação de listas utilizando `<ul>` e `<li>`
* Inserção de um rodapé utilizando `<footer>`
* Estruturação semântica básica de uma página

## Como Executar

1. Faça o download ou clone este repositório.
2. Abra o arquivo `index.html` em qualquer navegador moderno.
3. A página será exibida localmente.
